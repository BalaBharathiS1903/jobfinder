# Quick Reference Guide - New Features

## 🎯 Resume Analyzer → Course Suggestions

**Location:** `/resume-analyzer`

**What's New:**
- After analyzing resume, scroll down to see "Recommended Courses to Learn Missing Skills"
- Each course card shows missing skills in red badges
- Click **"Start Learning →"** button to go directly to that course
- Click **"View All Courses in Prep Hub →"** to browse all courses

**Example:**
```
📊 Data Science
Missing: numpy, pandas, matplotlib, scikit-learn
[Start Learning →]
```

## 💾 Save Resume from Builder

**Location:** `/resume-builder`

**How to Use:**
1. Build your resume (Steps 1-2)
2. Preview in Step 3
3. Click **"Save as Resume"** button
4. Resume is saved to database
5. Automatically redirected to `/resumes` page
6. Your resume now appears in the list

**Note:** You can have up to 5 resumes. The saved resume can be used for job matching.
